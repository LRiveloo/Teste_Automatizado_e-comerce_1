
Este repositório contém uma suíte de testes automatizados E2E para a aplicação [SauceDemo](https://www.saucedemo.com/), desenvolvida para demonstrar conceitos práticos de garantia de qualidade (QA) e automação em JavaScript.

Esse repositoria é apenas um teste simples e inicial de automação de um teste de login e compra de um e-comerce fictiocio. Desenvolvido apenas para me familiarizar inicialmente com as ferramentas de QA, sendo elas:
- **Node.js**
- **Cypress**
- **JavaScript**
